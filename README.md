# AI CLI WORK

Default workspace directory for the Antigravity CLI (`agy`).

## Overview
This folder is configured as your primary workspace when launching `agy` from the terminal.

- **Path**: `~/Desktop/AI CLI WORK`
- **CLI Command**: Typing `agy` from your default terminal session automatically launches into this workspace.
- **Customizations**: Project-specific rules and skills can be placed in `.agents/rules/` and `.agents/skills/`.

## Contents
- `Antigravity.tar.gz` — Antigravity Linux package archive
- `GEMINI.md` — Workspace instructions for the Antigravity agent
- `.agents/` — Custom rules and skills directory
